# Suits

Dört renk sembolü, 24×24 görünüm kutusu, dolgu biçiminde. Arayüzde `Suit` bileşeni aynı çizimleri satır içi kullanır; bu dosyalar PDF, e-posta, görsel gibi bileşenin çalışmadığı yerler içindir.

| Dosya | Mürekkep |
| --- | --- |
| `suit-spade.svg` (Pik) | `#1c1e1b` (`ink` / `suit-black`) |
| `suit-heart.svg` (Kupa) | `#b42318` (`suit-red`) |
| `suit-diamond.svg` (Karo) | `#b42318` (`suit-red`) |
| `suit-club.svg` (Sinek) | `#1c1e1b` (`ink` / `suit-black`) |

Koyu zeminde dosyalar yerine `Suit` bileşenini kullanın (koyu temada `suit-red` `#f2897e`, `suit-black` `#ebe5d6` olur).
